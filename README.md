This is a light and easy to use Java desktop application meant to help better a person's focus and ability to complete tasks. 

Features Included: 
- 25 Minute study countdown timer intervals with automatic micro-break triggers   
- Keeps track of your buddy's behavior ("IDLE", "STUDYING", "BREAK") 
- Uses an automated local file writer engine to track targets and reflections in a CSV file


How To Run this App:
1. Clone/download this repository.
2. Open the project in an IDE. 
3. Go to `src/main/java/com/example/StudySessionRecorder/AppWindow.java`.
3. Right click inside the `AppWindow.java` and click "Run" I(or click link here).
4. The desktop will open on your screen!
